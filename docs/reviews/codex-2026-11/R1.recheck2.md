### N2 [medium] [human] [high] 待審佇列上限高於可列出的提案數

- Store 允許 256 筆待審提案，但 `Proposals` 只能依 ID 由新到舊列出最多 64 筆，沒有分頁參數。編輯器只取 32 筆。當有 65 筆待審且交接時未保留最舊提案的 ID，審查者無法從列表取得它，必須先處理較新的提案。應加入以 ID 為游標的分頁，並讓編輯器載入下一頁。 [protocol.rs](/D:/rust_learn/.claude/worktrees/r1/crates/axiom-core/src/protocol.rs:37) · [store.rs](/D:/rust_learn/.claude/worktrees/r1/crates/axiom-core/src/store.rs:447) · [store.rs](/D:/rust_learn/.claude/worktrees/r1/crates/axiom-core/src/store.rs:466) · [app.rs](/D:/rust_learn/.claude/worktrees/r1/crates/axiom-runtime/src/app.rs:2883)
