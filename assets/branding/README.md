# Axiom brand marks

Owner-provided Axiom logo. Variants are derived from the original artwork:

| File | Use |
|---|---|
| `axiom-logo.png` | Full logo, transparent background (light surfaces) |
| `axiom-logo-white.png` | Full logo on a white card (README; safe on dark themes) |
| `axiom-icon-256.png` / `-64` / `-32` | Character mark for docs, window icon and editor toolbar |

`crates/axiom-runtime/src/branding.rs` embeds `axiom-icon-64.png` for native window icons and the editor toolbar. Regenerate the variants from the master artwork instead of editing them by hand.
